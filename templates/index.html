🪪 Greeting Card Generator

A tiny web app for an Application Security demo on Server-Side Template Injection (SSTI) leading to Remote Code Execution (RCE).

❌ Vulnerable version

User input is placed straight into the template that the server executes. Try entering {{7*7}} as the name.

Open vulnerable app

✅ Secure version

Same feature, but input is treated as data, not template code. The same payload is shown literally and never runs.

Open secure app

Runs on localhost only. For educational use in a controlled lab.
